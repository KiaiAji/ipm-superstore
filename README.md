# Analisis dan Visualisasi Data Penjualan Superstore

## Deskripsi
Proyek ini merupakan studi kasus mata kuliah Interaksi Manusia dan Komputer (IMK) menggunakan dataset Sample Superstore dari Kaggle. Analisis dilakukan untuk membandingkan penjualan dan keuntungan berdasarkan kategori produk.

## Tujuan
- Mengolah data penjualan menggunakan Python.
- Membandingkan total penjualan setiap kategori produk.
- Menampilkan visualisasi data dalam bentuk grafik.
- Menerapkan prinsip IMK melalui tampilan informasi yang sederhana dan mudah dipahami.

## Dataset
Sample Superstore Dataset  
Sumber: https://www.kaggle.com/datasets/vivek468/superstore-dataset-final

## Teknologi
- Python
- Pandas
- Matplotlib
- Jupyter Notebook / Google Colab

## Cara Menjalankan
1. Unduh dataset dari Kaggle.
2. Simpan file CSV di folder `data`.
3. Buka notebook menggunakan Jupyter Notebook atau Google Colab.
4. Jalankan setiap cell secara berurutan.

Instal library yang diperlukan:
```bash
pip install pandas matplotlib
```

## Analisis
1. Membaca dataset.
2. Memeriksa struktur dan data kosong.
3. Menghitung total penjualan per kategori.
4. Membuat grafik penjualan.
5. Menghitung total keuntungan per kategori.
6. Membuat grafik keuntungan.
7. Menampilkan kategori dengan penjualan dan keuntungan tertinggi.

## Penerapan Prinsip IMK
Grafik menggunakan judul dan label yang jelas serta tampilan sederhana untuk membantu pengguna memahami data dengan lebih cepat dan mengurangi beban kognitif.

## Kesimpulan
Visualisasi data membantu menyederhanakan informasi penjualan sehingga perbandingan kategori produk dan keuntungan lebih mudah dilakukan.
